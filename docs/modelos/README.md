# Documentación académica de los modelos

Cada documento describe un componente del laboratorio con la misma estructura:
**supuestos**, **ecuaciones**, **derivación**, **método de cálculo**, **ejemplos
numéricos** (obtenidos con los motores del proyecto, no calculados a mano por
separado), **interpretación** y **limitaciones**. Todas las calibraciones son
hipotéticas y tienen fines didácticos.

| Módulo | Documento | Contenido |
| --- | --- | --- |
| A | [IS-LM tradicional](is-lm-tradicional.md) | Modelo lineal de referencia con oferta monetaria exógena o tasa fijada. |
| B | [IS-LM avanzado](islm-avanzado.md) | Impuestos proporcionales, transferencias y tres especificaciones de la LM. |
| B | [LM no lineal](lm-no-lineal.md) | Demanda especulativa a/(i − i_min), dominio y pendiente variable. |
| B | [Trampa de liquidez](trampa-de-liquidez.md) | Zona asintótica y cota inferior estricta; eficacia relativa de las políticas. |
| B | [Impuestos y transferencias](impuestos-y-transferencias.md) | Estabilizador automático, multiplicadores de T₀, t y TR. |
| A–D | [Multiplicadores](multiplicadores.md) | Derivación por estática comparativa e interpretación del efecto desplazamiento. |
| C | [Construcción gráfica en cuatro cuadrantes](cuatro-cuadrantes.md) | Derivación de la IS y la LM desde sus mercados. |
| D | [Política fiscal](politica-fiscal.md) | Gasto, impuestos, transferencias, presupuesto equilibrado y acomodación. |
